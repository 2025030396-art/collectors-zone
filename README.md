# ⚡ Collector's Zone

Sitio web y catálogo interactivo de figuras coleccionables, réplicas y ediciones limitadas (Hot Toys, Bandai, Marvel, Star Wars y más).

## 🌟 Características

- **Página de Inicio (`index.html`):** Banner promocional dinámico, marcas destacadas, categorías y accesos directos al catálogo.
- **Catálogo Completo (`catalogo.html`):** Galería interactiva de figuras coleccionables con detalles, precios y opciones de compra/reserva.
- **Diseño Responsivo:** Adaptado a pantallas de escritorio y dispositivos móviles con CSS moderno.

## 🛠️ Tecnologías

- **HTML5** semántico
- **CSS3** (Flexbox, Grid, variables CSS)
- **Vanilla JavaScript**

## 🌐 Ver en Vivo (GitHub Pages)

Una vez activado GitHub Pages en este repositorio:
1. Ve a **Settings** > **Pages**.
2. En **Build and deployment > Source**, selecciona `Deploy from a branch`.
3. Selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save**. En unos minutos el sitio estará disponible en:
   `https://<tu-usuario>.github.io/<nombre-del-repositorio>/`
